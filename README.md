# Cindero — downloads

App de streaming de tela e câmera para Windows (Electron).

## Baixar e instalar

1. Vá em [**Versões**](../../releases) e baixe o `Cindero-Setup-X.Y.Z.exe` mais recente.
2. Execute o instalador e abra o **Cindero**.
3. Na tela de login, clique em **criar conta**: informe e-mail, usuário e senha.
4. Pegue o **código de 6 dígitos** enviado para seu e-mail e conclua o cadastro.
5. Adicione amigos pelo usuário e comece a transmitir.

## Requisitos

- Windows 10/11 64 bits
- Internet com pelo menos 10 Mbps de upload (para transmitir em 1080p)

O app se atualiza sozinho a cada nova versão publicada aqui.
